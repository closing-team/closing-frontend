# Login UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Figma LOG002 login screen with an API-ready Kakao login adapter and deterministic UI tests.

**Architecture:** `LoginPage` owns only screen state and navigation. The authentication operation is injected through an `onKakaoLogin` prop, returning a compact discriminated result type. A default local implementation allows the screen to work before the real Kakao/API integration is available.

**Tech Stack:** React 19, TypeScript, React Router, Tailwind CSS v4, Vitest, Testing Library.
